III. Google Sheet Assignment Ledger & Column Map

scripts/sync_gdrive.py reads rows where status is empty, new, or draft, validates metadata, opens/updates the standing PR on ingest/gdrive-sync, and pings Discord/email with the PR link and title. Internal notes are included in the PR review table and never written to the public markdown body.

Column Header Required Role in Pipeline
id Optional Canonical {lang}-{slug} identifier. Auto-generated from language and title if blank.
title Required Full title of the theoretical work.
author Required Author or party organ attribution.
year Required 4-digit year of composition or publication (^\d{4}$).
language Required Allowed 2-letter ISO code (en, es, pt, it, fr, de, nl, ru, zh, ja, ko, ar, hi, bn, id, tr, pl, el).
section_id Required Canonical taxonomy slug (critique-political-economy, party-state-revolution, historical-materialism, history-communist-left).
pdf_link Optional Google Drive file URL (or N/A if submitted via Form File Upload or external HTML only). Sets has-pdf label on PR.
source_url Optional Canonical source URL. If blank, sets empty-source label on PR.
description Optional Initial summary note; never overwrites an existing transcribed Markdown body.
assignee Ledger Moderator assigned to review the PR (surfaced in PR ledger table and Discord/email notification).
priority Ledger Editorial priority (e.g. high, normal, low).
notes Ledger Internal editorial notes for reviewers — never written to public markdown files.
status Required Lifecycle state: new → pending (or draft) → published (on PR merge) | error: ....
