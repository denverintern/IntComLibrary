        📊 Managing Library Entries via Google Sheets
      

      

        For moderators who prefer not to touch code, the library includes a built-in automated synchronizer (scripts/sync_gdrive.py). Simply edit your spreadsheet or have comrades submit entries through a Google Form, and GitHub Actions automatically generates the book pages, links the PDFs, and updates the site every 6 hours!
      


      
Required Column Structure in Your Google Sheet:

      

        

          
            

              Title
              Author
              Language
              Section
              Category
              Subcategory
              Description
              PDF Link

💡 How to Trigger an Immediate Sync:

        
    
          
  1. Add or modify your book rows in the Google Sheet.
    2. 
          
  2. Go to your repository on GitHub → Click the Actions tab.
    3. 
          
  3. Click Sync from Google Drive on the left sidebar.
    4. 
          
  4. Click the Run workflow button. Within 1 minute, all new books are created and deployed to the site!
